# Imagens originais do protótipo

Estas imagens são os ativos aprovados da experiência triobum. Os JSONs apontam para elas usando `assets/<nome>` e o build copia os arquivos para `dist/assets/`. Ajustes de recorte e compressão já foram feitos na iteração anterior; não substitua por screenshots da página nem embuta texto legível nas imagens. Alt text fica no JSON de cada componente. `src/assets/` é a origem editável; `assets/` na raiz existe para compatibilidade com o Preview antigo.

`shoe-ritmo.webp` é o render **conceitual** do terceiro tênis, adicionado para o sorteio da comparação; é um arquivo local incluído em `dist/` e no ZIP, sem dependência do armazenamento da plataforma ao hospedar em GitHub Pages.
